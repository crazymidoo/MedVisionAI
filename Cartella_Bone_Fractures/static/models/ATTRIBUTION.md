# Anatomical Model Attribution

This project includes anatomical geometry from the BodyParts3D database.

- Dataset: BodyParts3D / Anatomography
- Provider: Database Center for Life Science (DBCLS)
- Model used: Right humerus (FMA23130)
- Source archive: https://dbarchive.biosciencedbc.jp/data/bodyparts3d/20110915/BodyParts3D_3.0_obj_99.zip
